# Angara.Net: meteo38_bot

## Рассылка и избранное

Подписки и «⭐️ Избранное» отправляются одним сообщением-сводкой по всем станциям пользователя: пустая строка между станциями, значения с отступом (два эм-пробела + пробел, `\u2003\u2003 `), заголовок «📮 Погода»/«⭐ Избранное» при одиночном сообщении, избранное — первым. При превышении 4000 видимых символов сводка делится на несколько сообщений. Команда `/favs` сохраняет отдельную карточку каждой избранной станции с inline-кнопками управления. Кнопка «⭐️ Избранное» показывает общий дайджест.

Команды `/help` и `/subs` присылают основную клавиатуру. Для `/subs` она прикрепляется как к списку рассылок, так и к инструкции при отсутствии подписок. В конце справки после пустой строки выводится информация о сборке: `<название приложения> <версия> <краткий хэш коммита>` из `build-info.edn`. Дополнительное сообщение «⌨️ Меню» после команд не отправляется; существующие inline-кнопки управления сохраняются.

## Поиск станций

Обычный текст длиной от трёх символов (без пробелов по краям) запускает поиск по названию и описанию станций, активных за последние три часа. Регистр не учитывается, поиск выполняется по подстроке. Выдача сохраняет порядок активных станций по расстоянию от местоположения пользователя (или точки по умолчанию).

Результаты показываются по пять станций; inline-кнопки «⬅️»/«➡️» переключают страницы в том же сообщении. Если найдено от одной до пяти станций, к ответу прикрепляется обычная основная клавиатура вместо inline-кнопок. Кнопки «Активные станции» и «Помощь» добавляются только при отсутствии результатов. Ссылки `/info_<станция>` открывают карточки с кнопками управления. Если ничего не найдено, бот сообщает об этом и предлагает inline-кнопки «Активные станции» и «Помощь».

Последний поиск хранится отдельно для каждого чата десять минут. Новый поиск заменяет предыдущий; после истечения срока или перезапуска бота запрос нужно ввести заново. При тексте короче трёх символов (после удаления пробелов по краям) бот сообщает «Для поиска введите не менее 3 символов.» и прикрепляет основную клавиатуру. Неизвестные команды не запускают поиск. Кнопка «⭐️ Избранное» по-прежнему показывает дайджест.

Прототип: ветка `proto/digest`, файл `proto/one-message-digest.html`.

Тесты: `clojure -M:test`.
