# Angara.Net: meteo38_bot

## Рассылка и избранное

Подписки и «⭐️ Избранное» отправляются одним сообщением-сводкой по всем станциям пользователя: пустая строка между станциями, значения с отступом (эм-пробел + пробел, `\u2003 `), заголовок «📮 Погода»/«⭐ Избранное» при одиночном сообщении, избранное — первым. При превышении 4000 видимых символов сводка делится на несколько сообщений. Прототип: ветка `proto/digest`, файл `proto/one-message-digest.html`.

Тесты: `clojure -M:test`.
